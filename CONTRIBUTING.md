# Contributing

Thanks for wanting to make this guide better!

## Adding a new language

1. Copy the structure of `README.md` or an existing file in `guides/`.
2. Translate/write in your own words — don't machine-translate or copy from other prep repos/blogs. Keep the tone simple and friendly.
3. Save it as `guides/guide_<language-code>.md` (e.g. `guide_te.md` for Telugu, `guide_kn.md` for Kannada, `guide_ml.md` for Malayalam, `guide_mr.md` for Marathi, `guide_bn.md` for Bengali).
4. Add a link to it in the language switcher line at the top of `README.md` and every other guide file.

## Fixing content

- If exam weightage, course names, or links have changed, open a PR with a source/date so it's easy to verify.
- Keep sentences short. This guide is meant to be read in one sitting.

## Code of conduct

Be kind. This is a community effort to make one exam a little less confusing for the next person.
